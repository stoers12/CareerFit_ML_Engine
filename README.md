# CareerFit AI - ML Engine 🚀

## Overview
CareerFit AI is a data-driven Machine Learning engine built to revolutionize IT resume scoring. Bypassing rigid human biases, it uses Multiple Linear Regression (MLR) to dynamically discover the true weights of semantic context vs. lexical keyword matching. 

## Project Architecture 📂
This repository is structured for scalability and professional deployment:
- `data/`: Contains the processed datasets and CSV files used for model training.
- `notebooks/`: Includes the interactive Jupyter notebooks for the MLR engine.
- `models/`: Stores the serialized `.pkl` weights of the trained Hybrid Model.
- `docs/`: Contains the comprehensive Technical Architecture and Final Reports (PDFs).

## Tech Stack 🛠️
- **Language:** Python 3
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib
- **Core Methodologies:** LSA (Latent Semantic Analysis), TF-IDF, Multiple Linear Regression (MLR)
